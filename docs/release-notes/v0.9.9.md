# TelevyBackup 0.9.9

This release promotes the snapshot maintenance fixes validated in the 0.9.9 RC
series.

- Snapshot maintenance now exposes operation progress and preserves recoverable
  task state across refreshes.
- Stale snapshot inventory is classified before repair, and failed operations
  retain an actionable diagnostic instead of appearing idle.
- Release artifacts retain the verified Snapshot Access and mount-helper
  component identities from the RC acceptance path.
